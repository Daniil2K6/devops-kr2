# Ревизия шаблона КР2

Исходный шаблон: https://gitverse.ru/dgimatdinov/kr2-template, main, коммит 3ee6c4b.

| Файл и строка исходника | Дефект | Последствие | Исправление |
|---|---|---|---|
| Dockerfile 1 | python:latest | Базовая версия Python меняется, сборка может перестать работать; требуется лишняя загрузка | python:3.12-slim, как в ПР7 |
| Dockerfile 5, нет .dockerignore | COPY . . захватывает .env | Пароль попадает в образ и доступен получателям образа | Исключение .env и .git; точечный COPY |
| .env отслеживается Git | Пароль опубликован в шаблоне | Удаление файла не отзывает пароль из истории | git rm, .gitignore; новый случайный пароль только на ВМ |
| Dockerfile 5–6 | Код копируется до установки зависимостей | Любое изменение app.py повторно запускает pip install | Сначала COPY requirements.txt и pip, затем COPY app.py |
| Dockerfile, нет USER | Gunicorn работает от root | Компрометация приложения даёт права root в контейнере | Пользователь app, USER app |
| Dockerfile 9 | Shell-форма CMD | Shell становится PID 1 и может не передавать SIGTERM; остановка задерживается | Exec-форма JSON |
| Dockerfile 9 | bind 127.0.0.1 внутри контейнера | Запрос с проброшенного порта не приходит на loopback контейнера | 0.0.0.0:8001 |
| Dockerfile 8–9 | Порт 8000 вместо 8001 | Конфигурация не соответствует варианту 1 | EXPOSE 8001 и bind 8001 |
| Нет .env.example | Нет безопасного образца переменных | При настройке легко повторно использовать опубликованный пароль | Шаблон с заглушкой |

requirements.txt сохранён без изменения. В app.py разрешён только комментарий первой строкой.
